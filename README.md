# first-data-analysis

This repository originally contained road accident analysis artifacts.

## Creative Writing Assistant
A new CLI assistant has been added to help plan and draft:
- Novels
- Scripts
- Lyrics
- Scenes
- Dialogues

It is focused on a **raw, human tone** and **environment-aware writing**.

### Files
- `creative_writing_assistant.py` — interactive assistant builder.
- `WRITING_ASSISTANT_PLAN.md` — workflow and design guidance.

### Run
```bash
python3 creative_writing_assistant.py
```
