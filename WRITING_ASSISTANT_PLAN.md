# Writing Assistant Plan (Raw + Human)

## Objective
Build a practical assistant that helps create **novels, scripts, lyrics, scenes, and dialogue** with emotional realism and strong environmental grounding.

## Workflow
1. **Capture foundation**
   - Type of writing, genre, mood, and theme.
2. **Bind characters to place**
   - Physical setting, sensory cues, and social atmosphere.
3. **Define emotional engine**
   - Character desire, conflict, and consequence.
4. **Generate first draft**
   - Natural language, subtext, and imperfect human rhythm.
5. **Refine with targeted passes**
   - Tension pass, voice pass, environment pass.

## Core Design Rules
- Prioritize believable speech over polished phrasing.
- Let setting affect behavior (temperature, crowding, noise, class, time).
- Show emotions through actions and contradictions.
- Use concise but vivid detail to avoid generic scenes.
- End scenes with unresolved emotional charge when possible.

## Included Tool
Use `creative_writing_assistant.py` to:
- Build a personalized writing plan.
- Generate a reusable master prompt.
- Get follow-up prompts for multiple rewrites.

## Run
```bash
python3 creative_writing_assistant.py
```
